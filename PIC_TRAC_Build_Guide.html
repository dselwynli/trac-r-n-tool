PIC R&N TRAC Tool

Complete build guide - from a blank workbook to a working tool

An Excel/VBA reference tool for Injury Management Advisors and case managers: pick a treatment type (or search a keyword), and see the relevant Personal Injury Commission decisions on whether that treatment is reasonable and necessary, with the applicable Clinical Framework principle and a verbatim extract from each decision.

What you end up with

Four sheets, three of which stay hidden from normal use:

SheetVisible?Holds
PIC R&N TRAC ToolYesThe dropdown, search box, and results table - this is the only sheet anyone using the tool actually needs to see
PIC LibraryVery hiddenEvery case: category, case name, citation, outcome, Clinical Framework principle(s), summary, keywords, verbatim extract, source URL, and favourite status. This is the actual database.
PIC CategoriesVery hiddenThe unique list of categories, derived automatically from PIC Library - feeds the dropdown
CF PrinciplesVery hiddenThe 5 SIRA Clinical Framework guiding principles, referenced by number from PIC Library

"Very hidden" sheets don't show up in Excel's normal Unhide dialog - two macros (UnhidePICSheets / HidePICSheetsAgain) reveal and re-hide them when you need to edit the data directly.

Requirements

  • Excel with macros enabled (a macro-enabled workbook, .xlsm, or macros allowed in your .xlsx environment)
  • No add-ins or external libraries needed - this is plain VBA using only built-in Excel objects

Building it, step by step

1Open a blank workbook (or the workbook you want this tool to live in).
2Open the VBA editor - Alt+F11.
3Insert a Standard Module - in the Project Explorer (the tree on the left; Ctrl+R if you don't see it), right-click your workbook's project → Insert → Module. This creates a generic code container (e.g. "Module1") that isn't tied to any sheet.
4Paste Code block 1 (below) into that new Module. This holds all the shared logic and the full case library.
5Pick a sheet to be the tool's home screen. Any sheet works - a blank one is fine, or reuse an existing tab. In the Project Explorer, find it under "Microsoft Excel Objects" and double-click it (or right-click its tab in Excel itself → View Code) to open that sheet's own code window - a different place from the Module you just used.
6Paste Code block 2 (below) into that sheet's code window. It doesn't matter what the sheet is currently named or which one you picked - the setup code builds everything on whichever sheet this code is sitting in.
7Run it. With that sheet's code window open and active, press F5. Or go back into Excel, press Alt+F8, find RunSetupHere in the list (shown as something like "Sheet1.RunSetupHere") and run it from there.
That's it. RunSetupHere creates the three hidden data sheets, populates the case library, renames your chosen sheet to "PIC R&N TRAC Tool", and builds the dropdown, search box, and results table. A confirmation box will appear when it's done.
Why two separate code blocks, in two separate places? The dropdown and search box only work because Excel's Worksheet_Change event fires on code sitting inside a specific sheet's own module - not a generic Module. Code block 2 has to live with the sheet it's meant to control; pasting everything into one place (or putting block 2 into a Module instead) will compile, but nothing will actually respond when you use the dropdown.

Maintaining it

Hand-editing a case (fixing a citation, tweaking an extract, adding a new row)

  1. Alt+F8, run UnhidePICSheets.
  2. Go to the "PIC Library" tab. Columns: Category, CaseName, Citation, Outcome, Principle, Summary, Keywords, Extract, URL, Flag, Favorite. Edit any cell, or add a new case on the first blank row below the last one.
  3. Alt+F8, run HidePICSheetsAgain.
  4. Run RunSetupHere again if you changed a Category value (so the dropdown picks it up) or want a new row to show immediately.

Once the library has data in it, RunSetupHere never overwrites it again - your edits are safe across every future run.

Adding new cases without disturbing existing edits

Ask for a small standalone snippet - a short extra macro that appends just the new rows to the bottom of PIC Library without touching anything already there. This is the normal way to extend the tool over time.

Wiping everything and starting fresh

Run ResetPICLibraryToDefaults (Alt+F8). This asks for confirmation, then clears PIC Library completely - including any hand edits, added rows, and favourite stars - and rebuilds it from the AddRow list baked into Code block 1. Use this only if you genuinely want to discard everything and start over.

Design notes worth knowing

  • The VBA editor only reliably stores classic Windows-1252 (ANSI) text, not full Unicode. The star symbol is generated at runtime with ChrW(9733) rather than pasted as a literal character, because a literal star has no Windows-1252 equivalent and gets silently mangled into "?" the moment it's pasted into the editor. Ordinary punctuation like smart quotes and en-dashes (used throughout the case extracts) does have Windows-1252 equivalents, so those paste in fine as literal text.
  • Every finding in PIC Library is fact-specific to that decision's own circumstances (duration, evidence available at the time, that claimant's presentation) - none of it is a general verdict for or against any treatment modality. This matters in particular for entries about long-established or alternative therapies, where a blunt-sounding finding is about the specific facts of that case, not the modality in general.
  • Not every case has a captured source URL. Where one is missing, the Source column shows "-" instead of a broken link; the citation is still there to look up manually if needed.

Private Function GetOrCreateSheet(nm As String) As Worksheet
    Dim ws As Worksheet
    On Error Resume Next
    Set ws = ThisWorkbook.Worksheets(nm)
    On Error GoTo 0
    If ws Is Nothing Then
        Set ws = ThisWorkbook.Worksheets.Add(After:=ThisWorkbook.Worksheets(ThisWorkbook.Worksheets.Count))
        ws.Name = nm
    Else
        ws.Cells.Clear
    End If
    Set GetOrCreateSheet = ws
End Function

' expands a comma list of principle numbers e.g. "1,4" into "1 - Effectiveness; 4 - Function/RTW goals"
' blank input just returns a dash, dont bother looking anything up
Public Function ExpandPrinciples(codes As String) As String
    If Trim(codes) = "" Then
        ExpandPrinciples = "-"
        Exit Function
    End If

    Dim ws As Worksheet
    Set ws = ThisWorkbook.Worksheets(PRIN_SHEET)

    Dim parts() As String
    parts = Split(codes, ",")

    Dim i As Long
    Dim outStr As String
    outStr = ""
    For i = LBound(parts) To UBound(parts)
        Dim n As String
        n = Trim(parts(i))
        Dim lbl As String
        lbl = LookupPrincipleLabel(ws, n)
        If outStr <> "" Then outStr = outStr & "; "
        outStr = outStr & n & " - " & lbl
    Next i

    ExpandPrinciples = outStr
End Function

Private Function LookupPrincipleLabel(ws As Worksheet, num As String) As String
    Dim lastRow As Long
    lastRow = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row

    Dim r As Long
    For r = 2 To lastRow
        If CStr(ws.Cells(r, 1).Value) = num Then
            LookupPrincipleLabel = ws.Cells(r, 3).Value
            Exit Function
        End If
    Next r
    LookupPrincipleLabel = "?"
End Function

' populates the library ONLY if it's missing or empty - this is what makes hand edits (and
' favourites) stick. once you've edited cells directly, RunSetupHere will never overwrite them;
' it only rebuilds the Categories list (derived, safe) and the Lookup sheet chrome (also safe,
' no user data there). to add new cases later without disturbing your edits, use a small
' append-only snippet instead of this whole sub - ask for one when you've got new decisions to add.
' to wipe everything (including favourites) and start over from Davids original baseline, run
' ResetPICLibraryToDefaults.
Public Sub SetupPICLibrarySheet()
    Dim ws As Worksheet
    Dim isNew As Boolean
    On Error Resume Next
    Set ws = ThisWorkbook.Worksheets(LIB_SHEET)
    On Error GoTo 0

    If ws Is Nothing Then
        Set ws = ThisWorkbook.Worksheets.Add(After:=ThisWorkbook.Worksheets(ThisWorkbook.Worksheets.Count))
        ws.Name = LIB_SHEET
        isNew = True
    Else
        Dim lastRow As Long
        lastRow = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row
        isNew = (lastRow <= 1)
    End If

    ws.Visible = xlSheetVeryHidden
    If Not isNew Then Exit Sub

    PopulateLibraryDefaults ws
End Sub

' rebuilds the results table. scope = the selected TRAC Type (or everything, if left blank);
' within that scope, a keyword further narrows it if the search box has anything in it.
' favourited cases always sort first within whatever's showing; when TRAC Type is blank, the
' rest sort alphabetically by category. takes the sheet as a parameter for the same reason as
' SetupLookupSheet above - called from Worksheet_Change (passing Me) on the PIC Lookup sheet,
' from the double-click favourite handler, or from RunSetupHere
Public Sub RefreshResults(ws As Worksheet)
    Dim libWs As Worksheet
    Set libWs = ThisWorkbook.Worksheets(LIB_SHEET)

    Dim searchTerm As String
    searchTerm = Trim(ws.Range(SEARCH_CELL).Value)

    Dim selectedCat As String
    selectedCat = Trim(ws.Range(DROPDOWN_CELL).Value)

    ' clear old results first, formatting included, down to a generous row count
    Dim clearRange As Range
    Set clearRange = ws.Range("A7:J300")
    clearRange.ClearContents
    clearRange.Interior.ColorIndex = xlColorIndexNone
    clearRange.WrapText = False
    On Error Resume Next
    clearRange.Hyperlinks.Delete
    On Error GoTo 0

    Dim lastRow As Long
    lastRow = libWs.Cells(libWs.Rows.Count, 1).End(xlUp).Row

    ' pass 1: find every matching library row and build a sort key for it -
    ' favourites first ("0" sorts before "1"), then category alphabetically, then original order
    Dim matchRows() As Long
    Dim sortKeys() As String
    ReDim matchRows(1 To lastRow)
    ReDim sortKeys(1 To lastRow)
    Dim matchCount As Long
    matchCount = 0

    Dim r As Long
    For r = 2 To lastRow
        Dim inScope As Boolean
        If selectedCat = "" Then
            inScope = True
        Else
            inScope = (libWs.Cells(r, 1).Value = selectedCat)
        End If

        Dim keywordOk As Boolean
        If searchTerm = "" Then
            keywordOk = True
        Else
            keywordOk = (InStr(1, libWs.Cells(r, 7).Value, searchTerm, vbTextCompare) > 0)
        End If

        If inScope And keywordOk Then
            matchCount = matchCount + 1
            matchRows(matchCount) = r
            Dim favRank As String
            favRank = "1"
            If libWs.Cells(r, 11).Value = StarChar() Then favRank = "0"
            sortKeys(matchCount) = favRank & "|" & libWs.Cells(r, 1).Value & "|" & Format(r, "00000")
        End If
    Next r

    ' pass 2: selection sort on the keys (dataset is tiny, so simplicity beats speed here)
    Dim i As Long, j As Long, minIdx As Long
    Dim tmpKey As String, tmpRow As Long
    For i = 1 To matchCount - 1
        minIdx = i
        For j = i + 1 To matchCount
            If sortKeys(j) < sortKeys(minIdx) Then minIdx = j
        Next j
        If minIdx <> i Then
            tmpKey = sortKeys(i): sortKeys(i) = sortKeys(minIdx): sortKeys(minIdx) = tmpKey
            tmpRow = matchRows(i): matchRows(i) = matchRows(minIdx): matchRows(minIdx) = tmpRow
        End If
    Next i

    ' pass 3: write the sorted results out
    Dim outRow As Long
    outRow = 7

    For i = 1 To matchCount
        r = matchRows(i)

        Dim caseTxt As String
        caseTxt = libWs.Cells(r, 2).Value & " " & libWs.Cells(r, 3).Value
        Dim flagTxt As String
        flagTxt = libWs.Cells(r, 10).Value
        If flagTxt <> "" Then caseTxt = caseTxt & " [" & flagTxt & "]"

        ws.Cells(outRow, 1).Value = libWs.Cells(r, 1).Value
        ws.Cells(outRow, 1).WrapText = True
        ws.Cells(outRow, 2).Value = caseTxt
        ws.Cells(outRow, 2).WrapText = True
        ws.Cells(outRow, 3).Value = libWs.Cells(r, 4).Value
        ws.Cells(outRow, 4).Value = ExpandPrinciples(libWs.Cells(r, 5).Value)

        ws.Cells(outRow, 6).WrapText = True

        ws.Cells(outRow, 7).WrapText = True

        Dim srcUrl As String
        srcUrl = libWs.Cells(r, 9).Value
        If srcUrl <> "" Then

        Else

        End If

        If libWs.Cells(r, 11).Value = StarChar() Then
            ws.Cells(outRow, 9).Value = StarChar()

            ws.Cells(outRow, 9).Font.Bold = True
            ws.Cells(outRow, 9).Font.Size = 14
        End If
        ws.Cells(outRow, 9).HorizontalAlignment = xlCenter

        ws.Cells(outRow, 10).Value = r

        ColourOutcomeCell ws.Cells(outRow, 3), CStr(libWs.Cells(r, 4).Value)

        If (outRow Mod 2) = 1 Then
            ws.Range(ws.Cells(outRow, 1), ws.Cells(outRow, 8)).Interior.Color = RGB(232, 240, 255)
        End If

        outRow = outRow + 1
    Next i

    If outRow = 7 Then
        If searchTerm <> "" And selectedCat <> "" Then
            ws.Cells(7, 1).Value = "No decisions found for '" & searchTerm & "' under " & selectedCat & "."
        ElseIf searchTerm <> "" Then
            ws.Cells(7, 1).Value = "No decisions found for '" & searchTerm & "'."
        Else
            ws.Cells(7, 1).Value = "No PIC decisions currently held for this treatment type."
        End If
    End If

    ws.Rows("7:" & (outRow - 1)).AutoFit
End Sub

Private Sub ColourOutcomeCell(c As Range, outcome As String)
    If InStr(1, outcome, "Not R&N", vbTextCompare) > 0 Then
        c.Font.Color = RGB(192, 0, 0)
    ElseIf Left(outcome, 3) = "R&N" Then
        c.Font.Color = RGB(0, 128, 0)
    Else
        c.Font.Color = RGB(191, 143, 0)
    End If
    c.Font.Bold = True
End Sub

Option Explicit

Public Sub RunSetupHere()
    Dim wasScreenUpdating As Boolean
    wasScreenUpdating = Application.ScreenUpdating
    Application.ScreenUpdating = False
    Application.EnableEvents = False

    SetupPrinciplesSheet
    SetupPICLibrarySheet
    SetupCategoriesSheet
    SetupLookupSheet Me
    RefreshResults Me

    Application.EnableEvents = True
    Application.ScreenUpdating = wasScreenUpdating

    MsgBox "Setup done. Pick a TRAC Type from the dropdown, or type a keyword to search, on this sheet. Double-click a result row to star it as a favourite.", vbInformation
End Sub

' TRAC Type dropdown (DROPDOWN_CELL) and keyword search box (SEARCH_CELL) both live on this
' sheet. Either one changing just re-filters - no more clearing the other, since a keyword now
' searches within whatever TRAC Type is selected rather than overriding it
Private Sub Worksheet_Change(ByVal Target As Range)
    If Intersect(Target, Me.Range(DROPDOWN_CELL)) Is Nothing And Intersect(Target, Me.Range(SEARCH_CELL)) Is Nothing Then Exit Sub

    On Error GoTo CleanFail
    Application.EnableEvents = False
    RefreshResults Me
CleanFail:
    Application.EnableEvents = True
End Sub

' double-clicking any cell in a result row (row 7 down, within the results columns) toggles
' that case's favourite star. column J (hidden) holds which PIC Library row the clicked result
' row came from - that's how this knows what to toggle
Private Sub Worksheet_BeforeDoubleClick(ByVal Target As Range, Cancel As Boolean)
    If Target.Cells.Count > 1 Then Exit Sub
    If Target.Row < 7 Then Exit Sub
    If Target.Column > 9 Then Exit Sub

    Dim libRowRef As String
    libRowRef = CStr(Me.Cells(Target.Row, 10).Value)
    If libRowRef = "" Then Exit Sub

    Cancel = True

    Dim libWs As Worksheet
    Set libWs = ThisWorkbook.Worksheets(LIB_SHEET)
    Dim libRow As Long
    libRow = CLng(libRowRef)

    On Error GoTo CleanFail
    Application.EnableEvents = False

    If libWs.Cells(libRow, 11).Value = StarChar() Then
        libWs.Cells(libRow, 11).Value = ""
    Else
        libWs.Cells(libRow, 11).Value = StarChar()
    End If

    RefreshResults Me

CleanFail:
    Application.EnableEvents = True
End Sub
